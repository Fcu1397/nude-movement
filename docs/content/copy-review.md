# 文案檢視建議 (Copy Review)

## 1. 語意與易讀性建議

| 位置 | 原文 | 建議 | 理由 |
|---|---|---|---|
| SPEC §12 | Single / Discount | 單堂 / 月 4 堂優惠 | 避免讓使用者將「Discount」誤解為限時促銷的「原價與特價」，明確標示為「單堂」與「月 4 堂方案」的價格差異，能降低客服詢問成本。 |
| SPEC §17.02 | 須於次月前兩週內完成補課 | 須於次月前兩週（第一與第二週）內完成補課 | 依據 DECISIONS D10 定義，若直接寫出「第一與第二週」，能避免學員對「前兩週」的定義產生認知落差（例如從請假日算起的兩週）。 |
| SPEC §29 | 品牌名稱｜芭蕾・抒情當代・嬋柔・伸展課程 | Nude Movement｜芭蕾・抒情當代・嬋柔・伸展課程 | 依據 DECISIONS D10，將品牌名稱代入。 |

## 2. 商標標示建議 (Gyrokinesis®)

- **建議位置**：SPEC §9.2 Hero Description (`Ballet · Contemporary · Gyrokinesis · Stretching`) 或 SPEC §10.2 中文/英文標題處。
- **建議說明**：建議在網站中**首次出現**「Gyrokinesis」字樣時加上 ® 標記，成為「GYROKINESIS®」。並在該區塊底部（或 Footer）加上極小的商標聲明，以符合官方商標使用規範。
